Smart Mobility Cane

An IoT‑enabled cane that pairs GPS positioning with vibratory feedback to give its user localised guidance — modelled in MATLAB before a line of embedded C was written.

IoT GPS MATLAB Embedded C
On this page
Overview What I built Challenge Outcome

Overview

An assistive‑tech project: a mobility cane that knows roughly where it is and can nudge its user in the right direction through vibration, rather than sound — useful in settings where audio cues aren't practical.

What I built

  • Integration of a GPS module for localisation, paired with vibratory feedback motors to communicate direction to the user.
  • Mathematical modelling and signal filtering of raw sensor data in MATLAB, done before any of it touched the embedded target.
  • Deployment of the resulting filtering algorithms as C code running on the onboard microcontroller.

Challenge

Raw GPS and motion data is noisy, and a mobility aid can't afford to guess wrong. Modelling the filtering in MATLAB first meant I could validate the approach against real sensor traces before committing to a fixed‑point implementation on the microcontroller — catching problems on a laptop rather than in the field.

Outcome

A working prototype that translated filtered location data into timely, physical feedback the user could act on. It was also a useful lesson in taking a signal‑processing idea all the way from MATLAB modelling to a resource‑constrained microcontroller.
